01 — About

Neuro-symbolic AI
for knowledge graphs

I build neuro-symbolic graph neural networks for multi-omics data, with sepsis as the main application.

I construct knowledge graphs that link patient omics data to biomedical ontologies, and design relational GNNs that classify patients over these graphs. My current work is on interpretability: learning logical rules over sparse knowledge graphs so that predictions can be explained in symbolic terms.

03 — Research

Current & past work

PhD · Ongoing

Neuro-symbolic rule learning over knowledge graphs

Learning logical rules over sparse knowledge graphs to make link prediction and patient-level predictions interpretable, combining symbolic rule induction with graph neural networks.

PhD · EKAW 2026

W-RGCN

A Bayesian weighted relational GCN: each edge gets a learned mean and variance, modulated per relation, to classify patients over biomedical knowledge graphs.

Code
PhD · EGC 2025

OntoSepsisKG

An omics-based knowledge graph for sepsis that integrates multi-omics patient data with biomedical ontologies.

Results
IRIT · Toulouse

Boolean rules from spiking neural networks

An SNN-based system that extracts the Boolean logic rules learned by the network from its activation patterns, with an emphasis on causal reasoning.

University of Sussex

CNNs as spiking networks

Converted AlexNet, ResNet and MobileNet into spiking implementations and wrote tutorials for the open-source GeNN library.
